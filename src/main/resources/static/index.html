What SocketDrop does

A temporary room where everyone sees the same files. Nothing is saved to an account and nothing is kept after the room closes.

  1. 1

    Make a room

    You get a 6-letter code like K7Q9XD and a QR code straight away.

  2. 2

    Share the code

    Send the link in a chat, read the 6 letters out loud, or let someone scan the QR.

  3. 3

    Drop files

    Everyone in the room gets each file the moment it finishes uploading.

No sign-up

You get a random name automatically. No email, no password, no profile.

50 MB per file

Send as many as you like. They upload one at a time so nothing fails halfway.

Room-only access

Downloads only work for people currently in the room. Leave and you lose access.

Deletes itself

Hit Destroy to wipe every file and kick everyone out, or leave and let the last person out close it.

Real progress

Actual percentage, speed and time remaining. You can cancel any upload.

Any device

Phone, laptop or tablet. Same code, same room, same files.

Ready when you are

No account, nothing to install.
